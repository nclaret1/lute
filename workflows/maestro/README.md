# Maestro, AKA LWM, The LUTE Workflow Manager
This is a lightweight workflow manager built as a component of the [LUTE](https://github.com/slac-lcls/lute) project. 

It is provided as one possible backend workflow manager. For up-to-date documentation refer to the main [LUTE Docs](https://slac-lcls.github.io/lute/dev/).
